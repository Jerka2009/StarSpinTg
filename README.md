# StarSpin

Telegram-бот с игровой валютой и оплатой пополнений Telegram Stars. Python 3.10+, aiogram 3, SQLite.

## Запуск

1. Создай бота через `@BotFather` и скопируй токен.
2. Скопируй `.env.example` в `.env`, укажи `BOT_TOKEN` и Telegram ID администраторов в `ADMIN_IDS` (несколько ID можно разделить запятыми).
3. Если серверу нужен SOCKS5/HTTP-прокси для доступа к Telegram Bot API, укажи `BOT_PROXY_URL` в `.env` (например, `socks5://127.0.0.1:1080`). Прокси должен поддерживать HTTPS-запросы к `api.telegram.org:443`.
4. Установи зависимости и запусти:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Для Linux/macOS активируй окружение командой `source .venv/bin/activate`.

SQLite-файл `starspin.sqlite3` и журнал операций создаются автоматически. Регулярно делай резервную копию базы, останавливая бота перед копированием.

## Возможности

- Пополнение Telegram Stars: 1 ⭐ начисляет 10 фишек. Сумма Stars списывается самим Telegram; обработчик успешного платежа начисляет фишки один раз на уникальный идентификатор платежа.
- Игры: слот-машина, баскетбол, кубик и дартс через игровые эмодзи Telegram; 21; выбор стороны монеты; европейская рулетка с выбором цвета. После раунда можно ввести следующую ставку в той же игре; «Назад» завершает игровую сессию.
- Баланс и журнал операций, глобальный рейтинг десяти лидеров.
- Подарки активному пользователю по `@username` или Telegram ID: мишка, кристалл, подарок, торт, шампанское, роза и произвольный подарок с заданными названием и ценой. К подарку можно добавить подпись; отправки сохраняются в базе, получатель получает уведомление.
- Заявка на вывод от 1500 фишек: сумма резервируется; администратор отмечает выплату выполненной или отклоняет заявку, возвращая фишки.
- Поединки: вызов зарегистрированного игрока со ставкой, принятие/отклонение, пошаговая атака и защита. Победитель получает банк обоих игроков.
- Администрирование: панель `/admin` и кнопка администратора в главном меню позволяют найти игрока по ID, посмотреть его баланс, статус бана, подарки и последние операции, прибавить/списать фишки и обработать заявки. Также доступны `/ban user_id`, `/unban user_id`, `/setbalance user_id сумма`.

## Платежи и вывод

Покупка цифровых игровых фишек проходит через Telegram Stars (валюта `XTR`). Заявка на вывод в этой версии только резервирует фишки и ведёт учёт статуса; бот сам не отправляет выплаты. Администратор должен выполнить перевод по согласованным с игроком правилам и только после этого отметить заявку выполненной. Если заявка отклонена, фишки автоматически возвращаются на баланс.

Перед публичным запуском настрой правила проекта, возрастные ограничения и допустимость азартных игр и выплат в своей юрисдикции. Оператор отвечает за выполнение применимых правил Telegram и местного законодательства.
